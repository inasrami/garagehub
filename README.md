# GarageHub

Car community built with React, JavaScript, Vite and Supabase. Current development milestone: **Phase 3A: Car creation, editing, deletion and author permissions**.

## Setup

Use Node.js 22.12+ within Node 22, copy .env.example to .env, configure Supabase using [the setup guide](docs/SUPABASE_SETUP.md), then run:

```bash
npm install
npm run dev
npm test
npm run build
npm run preview
```


## Status

This intermediate milestone is not the final submission. The completed Functional Guide, architecture and deployment instructions arrive in Phase 4. The final app needs a live frontend URL in this README, a configured hosted backend, successful tests with two accounts, and the required Git history.

## Current milestone

Car creation, editing, deletion and author permissions. Later features are not claimed as complete in this snapshot. Source was prepared with the user's existing design; live Supabase integration and production deployment still require the user's project configuration.
